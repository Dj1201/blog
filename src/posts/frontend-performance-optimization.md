性能优化不是堆技巧，而是围绕用户体验做度量、定位、优化、验证。查询性能问题时，先判断慢在加载阶段、渲染阶段、交互阶段还是网络接口。

## 核心指标

常见指标：

- FCP：首次内容绘制。
- LCP：最大内容绘制，衡量首屏主要内容出现时间。
- CLS：布局偏移，衡量页面是否抖动。
- INP：交互响应，衡量用户交互延迟。
- TTFB：首字节时间，衡量服务器响应速度。

不要只看单个指标。内容站点更关注 LCP 和 CLS，交互型应用更关注 INP。

## 排查工具

- Chrome DevTools Network：看资源体积、接口耗时、缓存。
- Performance：看长任务、布局、绘制、脚本执行。
- Lighthouse：给出综合建议。
- PageSpeed Insights：查看线上页面数据。
- Bundle Analyzer：分析打包体积。

## 加载优化

常见手段：

- 减少首屏 JS 体积。
- 路由懒加载。
- 组件懒加载。
- 第三方脚本延迟加载。
- CSS 关键路径优化。
- 开启 gzip 或 brotli 压缩。
- 静态资源使用 CDN。

路由懒加载：

```js
const PostView = () => import('./views/PostView.vue');
```

## 代码分割

代码分割让用户先加载当前页面需要的代码。

适合拆分：

- 路由页面。
- 大型编辑器。
- 图表库。
- 富文本。
- 管理后台低频页面。

不要过度拆分。请求过多也会增加调度成本。

## 依赖体积优化

检查：

- 是否引入了整个工具库。
- 是否可以按需引入。
- 是否有重复依赖。
- 是否有更轻量替代。
- 是否真的需要这个库。

示例：只为了格式化日期，不一定要引入大型日期库。

## 图片优化

图片通常是页面最大资源。

策略：

- 使用合适尺寸。
- 使用 WebP/AVIF。
- 压缩图片。
- 首屏关键图优先加载。
- 非首屏图片懒加载。
- 设置 `width` 和 `height` 减少 CLS。

```html
<img src="/cover.webp" alt="封面" width="800" height="450" loading="lazy" />
```

## 字体优化

字体可能阻塞文本显示或导致布局变化。

优化：

- 减少字体文件数量。
- 使用系统字体。
- 字体子集化。
- 设置 `font-display: swap`。

```css
@font-face {
  font-family: "Demo";
  src: url("/demo.woff2") format("woff2");
  font-display: swap;
}
```

## 渲染优化

避免频繁回流：

- 批量 DOM 读写。
- 使用 `transform` 和 `opacity` 做动画。
- 避免循环中读取布局后立即写样式。
- 大列表使用分页或虚拟滚动。

长任务拆分：

```js
setTimeout(() => {
  heavyTaskPart();
}, 0);
```

也可以使用 Web Worker 处理 CPU 密集任务。

## 列表优化

列表性能问题常见于：

- 一次渲染几千条 DOM。
- 每项组件过重。
- 频繁筛选排序。
- key 不稳定。

优化：

- 分页。
- 无限滚动。
- 虚拟列表。
- 搜索防抖。
- 计算缓存。

## 请求优化

- 合并必要请求。
- 并发请求用 `Promise.all`。
- 缓存稳定数据。
- 避免重复请求。
- 接口支持分页。
- 慢接口增加 loading 和兜底状态。

并发示例：

```js
const [profile, posts] = await Promise.all([loadProfile(), loadPosts()]);
```

## 缓存优化

静态资源：

- 文件名 hash。
- 长缓存。
- CDN。

HTML：

- 短缓存或协商缓存。

接口：

- 根据业务决定缓存时间。
- 用户相关数据谨慎缓存。
- 配置、字典、文章内容适合缓存。

## 交互优化

- 输入搜索防抖。
- 滚动监听节流。
- 提交按钮防重复点击。
- 乐观更新提升反馈速度。
- 骨架屏减少等待感。
- 错误状态提供重试。

## 性能优化流程

1. 复现问题。
2. 记录指标。
3. 定位瓶颈。
4. 做最小有效改动。
5. 对比优化前后数据。
6. 观察是否有副作用。

不要凭感觉优化。没有度量，就不知道优化是否有效。

## 面试速查

- LCP：最大内容绘制。
- CLS：布局偏移。
- INP：交互响应。
- 首屏优化：减小资源、懒加载、CDN、缓存、SSR/SSG。
- 运行时优化：减少回流重绘、虚拟列表、防抖节流、Web Worker。
- 图片优化：压缩、尺寸、懒加载、现代格式。
- 缓存策略：hash 静态资源长缓存，HTML 短缓存。

性能优化最终要服务用户体验。先用工具定位，再选择收益最高的方案。
